# GamesRoms

Static ROM catalog and search engine indexing Archive.org collections (Amiga, MS-DOS, NES, SNES, MAME, and more), deployed on GitHub Pages.

## Screenshot

_Frontend not yet implemented — screenshot pending Phase 4._

## Stack

TypeScript (strict), Node.js, zod, Vite, MiniSearch, idb, GitHub Actions.

## Getting started

See [COMPILATION.md](COMPILATION.md) for installation, type checking, linting, testing, and build instructions.

## Attribution

This project indexes metadata only; every download link points directly to the source file on [archive.org](https://archive.org). Each catalog entry credits Archive.org and links back to its source item.
